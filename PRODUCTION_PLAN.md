# Production Plan

For 200 casinos, I would host the Angular site on Azure Static Web Apps, put a small Azure Functions API in front of the data, and run the Python scraper as an Azure Container Apps Job. That keeps the site fast and static while the scraper only consumes compute during its daily run. I would use Azure Database for PostgreSQL Flexible Server for casinos, offers, scrape history, source URLs, and review status. Each stored offer would include the source page and check time so a reviewer can trace every value.

I would schedule the job for 02:00 UTC daily. It would fetch casino pages politely with per-domain rate limits, bounded retries, and conditional requests, then use Azure OpenAI structured output plus deterministic validation. Invalid or changed terms would be marked for review instead of overwriting a trusted offer. Azure Monitor and Application Insights would track each run; alerts would email the operator if the job fails, a casino is stale, or required fields unexpectedly disappear.

PostgreSQL would use automated backups with 14-day retention and point-in-time restore; I would test a restore regularly. I would register the domain through a registrar, manage DNS in Azure DNS, point the site and API subdomains to their Azure endpoints, and use managed TLS certificates so all traffic is HTTPS.

For one region, modest database capacity, daily runs, monitoring, and low-volume model calls, I would budget roughly **$80-$200 per month**. The actual amount depends on region, database availability settings, retained history, and model usage; I would confirm it with the Azure pricing calculator before launch.
